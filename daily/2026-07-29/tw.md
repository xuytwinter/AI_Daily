1、支持耳語與情緒控制!Fish Audio 週年重磅發佈 S2.1Pro 實時對話語音模型

Fish Audio 在成立週年之際推出了其 最新 的生產級語音大模型 S2.1Pro，該模型專爲實時對話語音場景打造，具有極低的延遲和高擬真度交互能力，同時支持多說話人對話生成和高質量語音克隆。

![image.png](https://upload.chinaz.com/2026/0729/6392093257857185022660369.jpg)

> 【AiBase提要:】
> 🗣️ S2.1Pro 實現了約90毫秒的首幀音頻播放延遲，支持自然順暢的對話輪替。
> 🌐 模型覆蓋83種語言並採用統一的語音識別架構。
> 🎙️ 支持耳語與情緒控制，允許直接在文本中嵌入自由格式的括號標籤。

7、OpenRouter 推出專用 LangChain 集成包 一行字符串切 400 款模型

OpenRouter 推出了專用的 LangChain 集成包，使開發者能夠輕鬆接入 OpenRouter 背後的 400 多款模型和 70 多家提供商。該集成包簡化了模型路由流程，提升了開發效率，並優化了計費規則和故障轉移機制。

> 【AiBase提要:】
> ✅ 提供了專用的 LangChain 集成包，簡化了模型接入流程。
> 🔄 支持自動負載均衡、故障規避和跨提供商故障轉移。
> 💰 優化計費規則，未成功請求不產生費用，節省成本。

8、OpenAI 把安全審查塞進命令行：Codex Security CLI 開源，讓漏洞在 CI 裏自己現形

OpenAI 發佈了 Codex Security CLI 工具，旨在幫助開發者在代碼倉庫中識別和驗證安全漏洞，並將其整合進持續集成與交付流程中。該工具具有低門檻的使用方式，支持多種認證方式，並提供 TypeScript SDK 接口。

> 【AiBase提要:】

> 🔄 該工具可以集成到 CI/CD 流程中，實現自動化安全檢測。
> 🧩 開發者可以通過 npm 安裝並使用該工具，支持 TypeScript SDK 接口。
