1. Xiaomi open-sources terminal AI programming assistant MiMo Code, featuring a free top multimodal model

Xiaomi has open-sourced the terminal AI programming assistant MiMo Code V0.1.0, which is based on OpenCode for secondary development and is released under the MIT license. Its core highlights include a persistent memory system, a dedicated Harness system and Compose mode, as well as excellent performance on authoritative test sets.

![image.png](文章配图地址)

> AiBase Summary:
> 🧠 Persistent Memory System: Solves the issue of AI forgetfulness through three mechanisms: project memory, session checkpoints, and task progress.
> 🛠 Dedicated Harness System and Compose Mode: Enhances model and framework compatibility, achieving full-process automated coding.
> 📈 Excellent Performance on Authoritative Test Sets: Leads in scores compared to similar tools on SWE-Bench Pro and Terminal Bench2.

4. Google Releases DiffusionGemma: Trying to Speed Up AI Inference Using Text Diffusion Architecture

Google launched the experimental open-source model DiffusionGemma, which uses a text diffusion architecture to significantly improve AI generation efficiency. On specialized GPUs, its text generation speed can be up to four times faster, but it is still an experimental product, and it is recommended to use the standard version in production environments. Google has released the model under the Apache 2.0 license, encouraging the technical community to explore and co-create.
