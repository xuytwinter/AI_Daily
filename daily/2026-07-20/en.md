3. Mingshi Intelligence Opens MiniCPM-Robot: A 1.5B VLA Model Fully Released, Personal Developers Can Run It on Real Robots

Mingshi Intelligence has open-sourced the first embodied AI model series, MiniCPM-Robot, including a 1.5B parameter visual-language-action model that allows personal developers to run operations and target tracking on real robots. The model series includes MiniCPM-RobotManip, MiniCPM-RobotTrack, and the high-performance inference framework PhyAI, providing important support for the popularization of embodied intelligence.

![image.png](https://pic.chinaz.com/2026/0720/260720091747566582.jpg)

> 【AiBase Highlights:】
> 🧠 MiniCPM-RobotManip: A 1.5B parameter general-purpose visual-language-action model designed specifically for robot operations.
> 🔍 MiniCPM-RobotTrack: A compact model for real-world object tracking, enhancing robot perception capabilities.
> ⚙️ PhyAI: A high-performance inference framework that provides efficient support for embodied models, promoting the development of robot understanding, memory, and action capabilities.
> More Details: https://github.com/OpenBMB/MiniCPM-Robot
