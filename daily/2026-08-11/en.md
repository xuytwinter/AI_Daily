3. Tencent Open-Sources BrowserSkill: Giving AI Agents Independent Hands to Work

Tencent has open-sourced BrowserSkill, a browser automation tool designed specifically for AI agents. It can reuse the real login status of browsers, run without interrupting the user's current work, and achieve high compatibility with mainstream agents through CLI tools, significantly improving the efficiency and stability of AI in handling web tasks.

![image.png](https://upload.chinaz.com/2026/0811/6392203751767614668285327.png)

> 🖥 Run without interrupting current work, execute instructions in an independent window.
> ⚙️ Provide a simple `bsk` command-line tool, compatible with mainstream agents.

4. Meta Open-Sources 30B-Parameter Muse Glimmer: Targeting Local AI Agents on Consumer Hardware

The model has 30 billion parameters, is the open version of Muse Spark, supports multi-step agent tasks, and can run locally, emphasizing privacy protection.

> 【AiBase Highlights:】

> 🌐 The model supports multi-step agent tasks, including calling tools, writing code, and processing files.
