1. ドウボーが6月下旬に有料版をリリース予定：3つのサブスクリプション価格が公開され、第3四半期にはECとの連携で集客を強化

ドウボーは6月下旬に有料コンテンツを正式リリースし、Forceカンファレンスで同時に機能をアップデートする予定です。これは国内ユーザー数最多の大規模モデルが商業化において実質的な進展を遂げるきっかけとなります。第3四半期にはEC機能と組み合わせて有料シーンを整え、抖音商城への集客に向けた特定の補助金を提供します。第4四半期には本格的な安定運用に入る予定です。また、ドウボーは2026年までは有料ユーザーの浸透率を核心的な評価指標としていない予定です。

> 🔄 主流環境とのシームレスな切り替えを実現し、複数のローカルエージェントへのアクセスをサポートしています。

![image.png](https://pic.chinaz.com/2026/0602/26060211100459255352.jpg)

> 【AiBase要約:】
> 🎨 Krea2LoRAのトレーニング機能が全面的に公開され、ユーザーはスタイル、キャラクターまたはオブジェクトのLoRAをカスタマイズできます。
> ⚡ Krea2モデルは高性能な画像生成エンジンを核としており、曖昧な指示にも即座に対応し、高品質な画像を生成します。
> 🚀 Krea2LoRAは精度、品質、創造性の面で他のモデルより優れ、AI画像創作の個別化能力を向上させます。

8. GitHub Copilotが従量課金モードを正式リリース

GitHub Copilotが従量課金モードを正式リリースし、AIポイント消費の仕組みを導入し、これにより単一のコード補完ツールからインテリジェントエージェントプラットフォームへの転換を示しています。

![image.png](https://pic.chinaz.com/picmap/201901090940200192_0.jpg)

> 【AiBase要約:】
> 💡 GitHub Copilotは従量課金モードを採用し、ユーザーはAIポイントを消費してサービス費用を支払う必要があります。
> 🔄 このモードは従来の低価格無制限月額方式を変更し、コストをユーザー側に転嫁しています。
> 💰 高価値タスクであるコードレビューとクラウド上のインテリジェントエージェントタスクはポイント消費に含まれるため、頻繁利用者は予算に影響を与えます。
