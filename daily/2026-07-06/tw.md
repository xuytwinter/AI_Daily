5、Meta 調整 AI 開發節奏：Llama API 公共預覽版將於明日下線

Meta 宣佈將正式下線 Llama API 的公共預覽服務，該調整將於2026年7月6日生效。儘管 API 服務將停止響應，但 Llama 模型本身仍可正常獲取和使用。Meta 建議開發者儘快遷移至其他支持 Llama 模型的第三方服務商，並透露正在構建全新的開發者路徑，以提升開發效率和穩定性。

> 【AiBase提要:】
> 📅 Llama API 公共預覽版將於2026年7月6日正式下線。
> 🔄 Meta 建議開發者儘快遷移至其他支持 Llama 模型的第三方服務商。
> 🚀 Meta 正在構建全新的開發者路徑，以提供更高效、穩定的 AI 模型開發與部署方式。

> 【AiBase提要:】
> 📅 Gemini 3.5 Pro 正式發佈日期鎖定爲7月17日，與 DeepSeek V4 競爭。
> 🧠 Google 戰略調整，跳過舊版本微調，投入更多時間進行全新預訓練。
> 🎨 Gemini 3.5 Pro 提升前端生成能力，包括 UI 設計、代碼生成和 SVG 構建。
